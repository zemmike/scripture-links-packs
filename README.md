# Scripture Links – content packs

Downloadable content packs for the Scripture Links app. The app reads
`packs.json` from the latest release, downloads a pack (`*.db.gz`), checks its
SHA-256 and installs it. Each pack is a SQLite database.

| Pack | Content | Source and licence |
|---|---|---|
| `bible_elb1905` | Elberfelder Bibel (1905), German | Public domain; via [scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases) |
| `strongs` | Strong's Hebrew and Greek dictionaries, with the Strong's-tagged words of the KJV | Dictionary text (Strong, 1890/1894) public domain. JSON edition © Open Scriptures, [CC-BY-SA](https://creativecommons.org/licenses/by-sa/3.0/); this pack is shared under the same licence. KJV tags via scrollmapper/bible_databases |
| `fathers` | Church Fathers' commentary on Bible verses (English) | Public-domain translations only: Ante-Nicene and Nicene/Post-Nicene Fathers (ed. Schaff, 1885–1900), Catena Aurea (tr. Newman, 1841–45), Cyril of Alexandria on John (tr. Pusey/Randell, 1874–85). Selected from the [HistoricalChristianFaith Commentaries Database](https://github.com/HistoricalChristianFaith/Commentaries-Database); excerpts it holds from modern, copyrighted translations are not included |

Packs are built from the sources above; nothing here contains personal data.
